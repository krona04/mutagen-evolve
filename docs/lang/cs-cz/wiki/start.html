    Začínáme · 0.2.1

    Instalace a rychlý start

    Vyberte verzi modu a vyzkoušejte svou první proměnu.

    Na této stránce
    • Instalace modu Mutagen
    • První proměna
    • Řešení potíží

    Instalace modu Mutagen

    1. Použijte Minecraft Java Edition 1.21.1, Javu 21 a profil s Fabric nebo NeoForge.
    2. Stáhněte odpovídající sestavení na stránce verzí.
    3. Přidejte Architectury API a GeckoLib. Fabric vyžaduje také Fabric API.
    4. Soubory vložte do složky mods vybraného profilu. Při hře více hráčů musí server i hráči používat stejné sestavení Mutagenu.

    První proměna

    1. Vyrobte biologický pracovní stůl a na něm sestavte laboratorní vybavení.
    2. Odeberte mobovi vzorek injekční stříkačkou a prozkoumejte jeho kmen v sekvenátoru.
    3. Vyčistěte vzorek v centrifuze a připravte sérum v syntetizátoru.
    4. Použijte sérum ve hře a sledujte stav na ukazateli kmene. Více najdete v části Proměna.

    Řešení potíží

    Zkontrolujte, že mod i jeho závislosti odpovídají Minecraftu 1.21.1 a zvolenému zavaděči. Ve složce mods má být jen jedna verze Mutagenu. Při pádu hry se podívejte do logs/latest.log. Do hlášení chyby uveďte verzi modu a zavaděče.
