    Začínáme · 0.2

    Instalace a rychlý start

    Vyberte sestavení a spusťte svůj první experiment v Minecraftu.

    Na této stránce
    • Nainstalujte Mutagen
    • Vaše první proměna
    • Odstraňování problémů

    Nainstalujte Mutagen

    1. Použijte Minecraft Java Edition 1.21.1, Java 21 a profil Fabric nebo NeoForge.
    2. Vyberte odpovídající sestavení na stránka verze.
    3. Přidejte Aarchitektury API a GeckoLib. Fabric také vyžaduje Fabric API.
    4. Vložte soubory do složky profilu mods. Pro multiplayer potřebuje server a hráči stejné sestavení Mutagenu.

    Vaše první proměna

    1. Vytvořte Bio Workbench a vyrobte tam laboratorní vybavení.
    2. Seberte vzorek z davu a použijte Sequencer ke studiu jeho kmene.
    3. Vyčistěte vzorek v centrifuze a poté pomocí syntetizátoru vytvořte sérum.
    4. Použijte sérum v Minecraftu a sledujte ukazatel průběhu na panelu kmenů. Viz Transformation pro stupně a obrácení.

    Odstraňování problémů

    Zkontrolujte, že mod, závislosti a nakladač cílí na Minecraft 1.21.1 a že v mods je pouze jeden mutagen. Pokud hra spadne, podívejte se do logs/latest.log. Zahrňte svou verzi nakladače a modu do zprávy o chybě.
