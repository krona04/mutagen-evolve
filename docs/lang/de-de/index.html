Gameplay

Von der Probe zum Serum

Nehmen Sie eine Probe

Gehen Sie in Minecraft auf einen Mob zu und entnehmen Sie mit einer Spritze eine Probe.

Erforschen Sie die Sorte

Verwenden Sie den Sequenzer, um stärkere Seren freizuschalten. Drücken Sie G, um den Genbaum zu öffnen.

Reinigen Sie die Probe

Verarbeiten Sie es in der Zentrifuge, um ein gereinigtes Genom zu erhalten.

Machen Sie ein Serum

Kombinieren Sie ein Genom, eine mutagene Base und einen Katalysator im Synthesizer.

Sehen Sie sich illustrierte Rezepte an

Transformation

Fünf Mutationsstadien

  1. IInfektion1–20%

    Das erste passive Merkmal erscheint.

  2. IIManifestation21–40%

    Flecken des Mobs breiten sich auf deiner Haut aus.

  3. IIIMutation41–70%

    Ihr Körper beginnt, seine Form zu verändern.

  4. IVDominanz71–99%

    Fliegende Stämme gewinnen an Flug. Grifflose Formen verlieren die Nebenhand.

  5. VVollständiges Formular100%

    Du nimmst die Form des Mobs an. Die Veränderung hört auf zu verfallen.

Ihr Fortschritt kann zwischen den Dosen abnehmen. Sobald Sie die volle Form erreicht haben, verwenden Sie ein Umkehrserum, um zurückzukehren.

Installation

  1. Verwenden Sie Java 21 und ein Fabric- oder NeoForge-Profil für Minecraft 1.21.1.
  2. Installieren Sie Architectury API und GeckoLib. Fabric benötigt außerdem Fabric API.
  3. Legen Sie die passenden Dateien im Ordner mods des Profils ab.

Pehkui ist optional für die Körperskalierung.
