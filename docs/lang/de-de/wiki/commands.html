    Bedienerbefehle

    Die Befehlsgruppe erfordert Berechtigungsstufe 2. Stämme akzeptieren eine ID wie mutagen:zombie oder den Kurznamen zombie. Klammern schließen optionale Argumente ein.

    BefehlAktion
    /mutagen status [target]Belastung, Fortschritt und andere Zustände anzeigen.
    /mutagen listVerfügbare Stämme auflisten.
    /mutagen dose <strain> [quality]Fügen Sie eine Dosis hinzu und umgehen Sie dabei die normale Forschungsobergrenze. Die Qualität reicht von 1 bis 100.
    /mutagen set <strain> <progress>Stellen Sie den Transformationsfortschritt von 0 bis 100 ein.
    /mutagen lock <true|false>Aktivieren oder deaktivieren Sie die Fortschrittssperre.
    /mutagen clearAktive Stämme löschen.
    /mutagen researchForschungsfortschritt anzeigen.
    /mutagen research <strain> <percent>Stellen Sie die Suche nach einer Sorte ein.
    /mutagen abilitiesZeigt die aktiven Fähigkeiten und Abklingzeiten an.
    /mutagen use <index>Versuchen Sie, eine Fähigkeit per Index zu aktivieren.
