    Konfigurationsdatei

    Finden Sie die Einstellungen in config/mutagen.json. Setzen Sie knowledgeScope auf player für separate Forschung pro Spieler. humanityPenalties kontrolliert Einschränkungen wie den Verlust der Verwendung von Werkzeugen in handlosen Formularen.

    Standardwerte

    SchlüsselStandardWas es tut
    transformationSpeed1.0Wie schnell Dosen einziehen und nachlassen
    doseStrength20.0Wie viel eine 100 %-ige Reinheitsdosis hinzufügt
    humanityPenaltiestrueHände, Rüstung usw. verlieren
    sunlightBurntrueUntote Stämme, die bei Tageslicht brennen
    hudtrueZeigt das Dehnungsfeld an
    hudCornertop_leftPanelposition: top_left, top_right, bottom_right, bottom_left
    fullFormRendertrueZeichne dich als echten Mob auf Stufe V
    maxGenes1Wie viele Belastungen kann ein Körper aushalten? Chimären kommen später
    knowledgeScopeworldworld: Jeder teilt seine Forschung. player: Jeder Spieler hat sein eigenes
    researchSpeed1.0Wie viel Sie jeder Sequenzer-Lauf lernt
    doubleSerumPurity85.0Genomreinheit für zwei Ampullen pro Synthese; 101 schaltet es aus
    hybridRendertrueDie Teile der Kreatur auf Ihrem Körper in den Stadien II–IV
    bodyMorphtrueDeine Proportionen und Körperhaltung verändern sich
    bodyMotiontrueKrämpfe zwischen den Stadien und Zuckungen später
    pehkuiIntegrationtrueVerwenden Sie Pehkui für die Körpergröße, wenn es installiert ist
    mobVisionfalseKreaturenvision. Wird auch mit N umgeschaltet

    Kompatibilität

    ModNotizen
    PehkuiBerücksichtigt die Körpergröße, falls installiert. Mit pehkuiIntegration ausschalten
    Natrium / EmbeddiumFunktioniert einwandfrei
    Iris / OculusFunktioniert; Mutationsüberlagerungen überspringen den Schattendurchgang
    Skin- und Cape-ModsIhre Haut ist alles, was sie Ihnen gibt. Der Umhang verschwindet in voller Form
    FiguraIhr Avatar könnte die Hybridform oder die Vollform abdecken. Schalten Sie hybridRender / fullFormRender aus, wenn sie kämpfen
