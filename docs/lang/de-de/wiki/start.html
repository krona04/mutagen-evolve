    Erste Schritte · 0.2.1

    Installation und Schnellstart

    Wählen Sie einen Build und führen Sie Ihr erstes Experiment in Minecraft durch.

    Auf dieser Seite
    • Mutagen installieren
    • Deine erste Transformation
    • Fehlerbehebung

    Mutagen installieren

    1. Nutze Minecraft Java Edition 1.21.1, Java 21 und ein Profil mit Fabric oder NeoForge.
    2. Lade die passende Datei von der Versionsseite herunter.
    3. Installiere Architectury API und GeckoLib. Für Fabric brauchst du außerdem Fabric API.
    4. Lege die Dateien im Ordner mods deines Profils ab. Im Mehrspielermodus müssen Server und Spieler dieselbe Mutagen-Version verwenden.

    Deine erste Transformation

    1. Bauen Sie eine Bio-Werkbank und stellen Sie dort die Laborausrüstung her.
    2. Sammle eine Probe von einem Mob und verwende den Sequenzer, um seinen Stamm zu untersuchen.
    3. Reinigen Sie eine Probe in der Zentrifuge und verwenden Sie dann den Synthesizer, um Serum herzustellen.
    4. Verwende das Serum in Minecraft und beobachte den Fortschrittsbalken im Stammfenster. Siehe Transformation für die Stufen und die Umkehrung.

    Fehlerbehebung

    Überprüfen Sie, ob der Mod, die Abhängigkeiten und der Loader auf Minecraft 1.21.1 abzielen und dass es in mods nur einen Mutagen-Build gibt. Wenn das Spiel abstürzt, schauen Sie in logs/latest.log nach. Fügen Sie Ihre Loader- und Mod-Versionen in einen Fehlerbericht ein.
