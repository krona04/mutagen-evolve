    Administration · 0.2.1

    Datapacks

    Create, override or configure fictional mob strains for your Minecraft world.

    On this page
    • Make a strain
    • Strain, body and vision fields
    • Trait types
    • Ability types
    • Examples and troubleshooting

    Make a strain

    1. Create a datapack in the world’s datapacks folder with a pack.mcmeta for Minecraft 1.21.1.
    2. Place a strain at data/<namespace>/mutagen/strains/<name>.json.
    3. Run /reload and look for the strain in /mutagen list. If the file is skipped, check the server log.

    Server datapacks sync to players. Everyone still needs the same build of Mutagen.

    {"entity":"minecraft:witch","color":"#6A2C8C","difficulty":2}

    absorb[]Player bones that should melt into the torso. Bones with no matching part do this automatically
    spreadright arm, body, left arm, head, legsThe order bones start changing and the skin spreads
    skincolorOnly for the first-person hand and the older method: texture takes infection colours from the mob's texture (player-shaped textures only), color uses the strain colour

    from_stagemanifestationWhen the vision starts. It gets stronger with progress and is full at 100%

    Examples and troubleshooting

    To replace a built-in strain, use its original file path under data/mutagen/mutagen/strains/. For custom names and descriptions you can use translations from a resource pack.

    See the full datapack specification for model mapping, vision effects and working examples.
