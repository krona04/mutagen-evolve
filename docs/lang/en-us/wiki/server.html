    Administration · 0.2.1

    Server configuration

    Defaults, compatibility and settings for a shared world.

    On this page
    • Configuration file
    • Default values
    • Compatibility

    Configuration file

    Find the settings in config/mutagen.json. Set knowledgeScope to player for separate research per player. humanityPenalties controls restrictions such as losing the use of tools in handless forms.

    Default values

    KeyDefaultWhat it does
    transformationSpeed1.0How fast doses absorb and wear off
    doseStrength20.0How much one 100%-purity dose adds
    humanityPenaltiestrueLosing hands, armour and so on
    sunlightBurntrueUndead strains burning in daylight
    hudtrueShows the strain panel
    hudCornertop_leftPanel position: top_left, top_right, bottom_right, bottom_left
    fullFormRendertrueDraw you as the actual mob at stage V
    maxGenes1How many strains one body can hold. Chimeras come later
    knowledgeScopeworldworld: everyone shares research. player: each player has their own
    researchSpeed1.0How much each sequencer run teaches you
    doubleSerumPurity85.0Genome purity for two ampoules per synthesis; 101 turns it off
    hybridRendertrueThe creature's parts on your body at stages II–IV
    bodyMorphtrueYour proportions and posture change
    bodyMotiontrueConvulsions between stages and twitching later on
    pehkuiIntegrationtrueUse Pehkui for body size if it's installed
    mobVisionfalseCreature vision. Also toggled with N

    Compatibility

    ModNotes
    PehkuiHandles body size if installed. Turn off with pehkuiIntegration
    Sodium / EmbeddiumWorks fine
    Iris / OculusWorks; mutation overlays skip the shadow pass
    Skin and cape modsYour skin is whatever they give you. The cape disappears in full form
    FiguraYour avatar might cover the hybrid or the full form. Turn off hybridRender / fullFormRender if they fight
