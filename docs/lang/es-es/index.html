Jugabilidad

De la muestra al suero

Recoger una muestra

Acércate a una mafia en Minecraft y usa una jeringa para recolectar una muestra.

Investiga la cepa

Usa el secuenciador para desbloquear sueros más fuertes. Presione G para abrir el árbol genético.

Purificar la muestra

Procesarlo en la Centrífuga para obtener un genoma purificado.

Hacer un suero

Combina un genoma, una base mutágena y un catalizador en el sintetizador.

Ver recetas ilustradas

Transformación

Cinco etapas de mutación

  1. yoInfección1–20%

    Aparece el primer rasgo pasivo.

  2. IIManifestación21–40%

    Parches de la mafia se extienden por tu piel.

  3. IIIMutación41–70%

    Tu cuerpo comienza a cambiar de forma.

  4. IVDominación71–99%

    Las cepas voladoras ganan vuelo. Las formas sin mango pierden la mano izquierda.

  5. VFormulario completo100%

    Tomas la forma de la mafia. El cambio deja de decaer.

Su progreso puede disminuir entre dosis. Una vez que alcance su forma completa, use un suero reverso para regresar.

Instalación

  1. Utilice Java 21 y un perfil Fabric o NeoForge para Minecraft 1.21.1.
  2. Instale Architectury API y GeckoLib. La tela también necesita Fabric API.
  3. Coloque los archivos coincidentes en la carpeta mods del perfil.

Pehkui es opcional para escalado corporal.
