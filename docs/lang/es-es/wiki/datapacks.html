    Administración · 0.2.1

    Paquetes de datos

    Crea, anula o configura cepas de mafias ficticias para tu mundo de Minecraft.

    En esta página
    • Hacer una cepa
    • Campos de tensión, corporales y visuales
    • Tipos de rasgos
    • Tipos de habilidad
    • Ejemplos y solución de problemas

    Hacer una cepa

    1. Cree un paquete de datos en la carpeta datapacks del mundo con un pack.mcmeta para Minecraft 1.21.1.
    2. Coloque una cepa en data/<namespace>/mutagen/strains/<name>.json.
    3. Ejecute /reload y busque la cepa en /mutagen list. Si se omite el archivo, consulte el registro del servidor.

    Los paquetes de datos del servidor se sincronizan con los reproductores. Todo el mundo sigue necesitando la misma versión de Mutagen.

    {"entity":"minecraft:witch","color":"#6A2C8C","difficulty":2}

    Ejemplos y solución de problemas

    Para reemplazar una cepa incorporada, use su ruta de archivo original en data/mutagen/mutagen/strains/. Para nombres y descripciones personalizados, puede utilizar traducciones de un paquete de recursos.

    Ver el especificación completa del paquete de datos para mapeo de modelos, efectos de visión y ejemplos de trabajo.
