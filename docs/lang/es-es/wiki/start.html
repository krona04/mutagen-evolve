    Empezando · 0.2.1

    Instalación e inicio rápido

    Elige una compilación y ejecuta tu primer experimento en Minecraft.

    En esta página
    • Instalar mutágeno
    • Tu primera transformación
    • Solución de problemas

    Instalar mutágeno

    1. Utilice Minecraft Java Edition 1.21.1, Java 21 y un perfil Fabric o NeoForge.
    2. Elija la versión correspondiente en el página de versiones.
    3. Agregue Architectury API y GeckoLib. Fabric también requiere Fabric API.
    4. Coloque los archivos en la carpeta mods del perfil. Para el modo multijugador, el servidor y los jugadores necesitan la misma versión de Mutagen.

    Tu primera transformación

    1. Crea un banco de trabajo biológico y construye allí el equipo de laboratorio.
    2. Recoge una muestra de una mafia y usa el secuenciador para estudiar su cepa.
    3. Purifique una muestra en la centrífuga y luego use el sintetizador para producir suero.
    4. Usa el suero en Minecraft y observa la barra de progreso en el panel de cepas. Consulte Transformation para conocer las etapas y la reversión.

    Solución de problemas

    Verifique que el mod, las dependencias y el cargador tengan como objetivo Minecraft 1.21.1 y que solo haya una compilación Mutagen en mods. Si el juego falla, mira en logs/latest.log. Incluya las versiones de su cargador y mod en un informe de error.
