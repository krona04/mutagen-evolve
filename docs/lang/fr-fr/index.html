Gameplay

De l'échantillon au sérum

Prélever un échantillon

Approchez-vous d'une foule dans Minecraft et utilisez une seringue pour prélever un échantillon.

Recherchez la souche

Utilisez le séquenceur pour débloquer des sérums plus puissants. Appuyez sur G pour ouvrir l'arbre génétique.

Purifier l'échantillon

Traitez-le à la Centrifugeuse pour obtenir un génome purifié.

Faire un sérum

Combinez un génome, une base mutagène et un catalyseur dans le synthétiseur.

Transformation

Cinq étapes de mutation

  1. JeInfection1–20%

    Le premier trait passif apparaît.

  2. IIManifestation21–40%

    Des taches de la foule s'étalent sur votre peau.

  3. IIIMutation41–70%

    Votre corps commence à changer de forme.

  4. IVDomination71–99%

    Les souches volantes prennent leur envol. Les formes sans poignées perdent leur côté secondaire.

  5. VFormulaire complet100%

    Vous prenez la forme de la foule. Le changement cesse de se dégrader.

Vos progrès peuvent diminuer entre les doses. Une fois que vous avez atteint votre pleine forme, utilisez un sérum d’inversion pour revenir en arrière.

Installation

  1. Utilisez Java 21 et un profil Fabric ou NeoForge pour Minecraft 1.21.1.
  2. Installez Architectury API et GeckoLib. Le tissu a également besoin de Fabric API.
  3. Placez les fichiers correspondants dans le dossier mods du profil.

Pehkui est facultatif pour la mise à l'échelle du corps.
