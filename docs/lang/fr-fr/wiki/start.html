    Mise en route · 0.2.1

    Installation et démarrage rapide

    Choisissez une version et exécutez votre première expérience dans Minecraft.

    Sur cette page
    • Installer Mutagen
    • Votre première transformation
    • Dépannage

    Installer Mutagen

    1. Utilisez Minecraft Java Edition 1.21.1, Java 21 et un profil Fabric ou NeoForge.
    2. Téléchargez le fichier adapté sur la page des versions.
    3. Installez Architectury API et GeckoLib. Pour Fabric, ajoutez aussi Fabric API.
    4. Placez les fichiers dans le dossier mods de votre profil. En multijoueur, le serveur et les joueurs doivent utiliser la même version de Mutagen.

    Votre première transformation

    1. Fabriquez un établi biologique et fabriquez-y l'équipement de laboratoire.
    2. Récupérez un échantillon sur une foule et utilisez le séquenceur pour étudier sa souche.
    3. Purifiez un échantillon dans la centrifugeuse, puis utilisez le synthétiseur pour fabriquer du sérum.
    4. Utilisez le sérum dans Minecraft et regardez la barre de progression dans le panneau de souche. Voir Transformation pour les étapes et l'inversion.

    Dépannage

    Vérifiez que le mod, les dépendances et le chargeur ciblent Minecraft 1.21.1 et qu'il n'y a qu'un seul build Mutagen dans mods. Si le jeu plante, regardez dans logs/latest.log. Incluez vos versions de chargeur et de mod dans un rapport de bug.
