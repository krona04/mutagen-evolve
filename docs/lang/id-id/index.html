Minecraft Java Edition · Akses Awal 0.2.1

Berubahlah menjadi mob.

Bangun laboratorium, teliti 12 strain, dan dapatkan kemampuan serta kelemahan makhluk Minecraft.

Unduh 0.2.1Buka wiki
Minecraft 1.21.1Java 21Fabric / NeoForge

Permainan

Dari sampel ke serum

Kumpulkan sampel

Dekati gerombolan di Minecraft dan gunakan jarum suntik untuk mengumpulkan sampel.

Teliti strainnya

Gunakan Sequencer untuk membuka serum yang lebih kuat. Tekan G untuk membuka Pohon Gene.

Purifikasi sampel

Prosesnya di Centrifuge untuk mendapatkan genom yang dimurnikan.

Buat serumnya

Gabungkan genom, basis mutagen, dan katalis dalam Synthesizer.

Lihat resep perakitan bergambar

Transformasi

Lima tahap mutasi

  1. IInfeksi1–20%

    Sifat pasif pertama muncul.

  2. IIManifestasi21–40%

    Bercak massa tersebar di kulit Anda.

  3. IIIMutasi41–70%

    Tubuhmu mulai berubah bentuk.

  4. IVDominasi71–99%

    Strain terbang dapat terbang. Bentuk-bentuk yang tidak dapat ditangani akan hilang begitu saja.

  5. VWujud penuh100%

    Anda mengambil formulir massa. Perubahan berhenti membusuk.

Perubahan dapat berkurang di antara dosis. Jika sudah mencapai wujud penuh, gunakan serum pembalik untuk kembali.

Instal Mutagen

  1. Gunakan Minecraft Java Edition 1.21.1, Java 21, dan profil Fabric atau NeoForge.
  2. Pasang Architectury API dan GeckoLib. Untuk Fabric, pasang juga Fabric API.
  3. Masukkan berkas ke folder mods profil. Untuk multipemain, server dan semua pemain harus memakai build Mutagen yang sama.

Pehkui bersifat opsional untuk perubahan ukuran tubuh.
