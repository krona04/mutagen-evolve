Minecraft Edisi Java / Akses Awal 0.2

Berubahlah menjadi mob.

Teliti 12 strain, bangun laboratorium, dan hadapi kemampuan dan kelemahan makhluk Minecraft.

Unduh 0.2Buka wiki
Minecraft 1.21.1Jawa 21Kain / NeoForge

Permainan

Dari sampel ke serum

Kumpulkan sampel

Dekati gerombolan di Minecraft dan gunakan jarum suntik untuk mengumpulkan sampel.

Teliti strainnya

Gunakan Sequencer untuk membuka serum yang lebih kuat. Tekan G untuk membuka Pohon Gene.

Purifikasi sampel

Prosesnya di Centrifuge untuk mendapatkan genom yang dimurnikan.

Buat serumnya

Gabungkan genom, basis mutagen, dan katalis dalam Synthesizer.

Lihat resep bergambar

Transformasi

Lima tahap mutasi

  1. SayaInfeksi1–20%

    Sifat pasif pertama muncul.

  2. IIManifestasi21–40%

    Bercak massa tersebar di kulit Anda.

  3. AKU AKU AKUMutasi41–70%

    Tubuhmu mulai berubah bentuk.

  4. IVDominasi71–99%

    Strain terbang dapat terbang. Bentuk-bentuk yang tidak dapat ditangani akan hilang begitu saja.

  5. VBentuk lengkap100%

    Anda mengambil formulir massa. Perubahan berhenti membusuk.

Kemajuan Anda dapat menurun antar dosis. Setelah Anda mencapai bentuk penuh, gunakan serum pembalikan untuk mengembalikannya.

Instalasi

  1. Gunakan Java 21 dan profil Fabric atau NeoForge untuk Minecraft 1.21.1.
  2. Instal AArchitecture API dan GeckoLib. Kain juga membutuhkan Fabric API.
  3. Letakkan file yang cocok di folder mods profil.

Pehkui bersifat opsional untuk penskalaan bodi.
