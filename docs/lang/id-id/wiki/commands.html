    Kontrol dan perintah

    Pintasan pemain dan perintah operator untuk menguji ketegangan.

    Di halaman ini
    • Kontrol pemain
    • Perintah operator

    Kontrol pemain

    KunciAksi
    GBuka Pohon Gen
    NAlihkan penglihatan makhluk
    RGunakan kemampuan tahap II
    VGunakan kemampuan tahap III
    BGunakan kemampuan puncak

    Perintah operator

    Grup perintah memerlukan izin tingkat 2. Strain menerima ID seperti mutagen:zombie atau nama pendek zombie. Tanda kurung mengapit argumen opsional.

    PerintahAksi
    /mutagen status [target]Tunjukkan ketegangan, kemajuan, dan keadaan lainnya.
    /mutagen listDaftar strain yang tersedia.
    /mutagen dose <strain> [quality]Tambahkan dosis sambil melewati batas penelitian normal. Kualitas berkisar dari 1 hingga 100.
    /mutagen set <strain> <progress>Tetapkan kemajuan transformasi dari 0 hingga 100.
    /mutagen lock <true|false>Mengaktifkan atau menonaktifkan kunci kemajuan.
    /mutagen clearHapus strain aktif.
    /mutagen researchTunjukkan kemajuan penelitian.
    /mutagen research <strain> <percent>Tetapkan penelitian untuk suatu strain.
    /mutagen abilitiesTampilkan kemampuan aktif dan cooldown.
    /mutagen use <index>Cobalah untuk mengaktifkan kemampuan berdasarkan indeks.
