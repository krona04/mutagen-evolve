    Administrasi · 0.2.1

    Paket data

    Buat, ganti, atau konfigurasikan rangkaian massa fiksi untuk dunia Minecraft Anda.

    Di halaman ini
    • Buat ketegangan
    • Ketegangan, bidang tubuh dan penglihatan
    • Tipe sifat
    • Jenis kemampuan
    • Contoh dan pemecahan masalah

    Buat ketegangan

    1. Buat paket data di folder datapacks dunia dengan pack.mcmeta untuk Minecraft 1.21.1.
    2. Tempatkan ketegangan pada data/<namespace>/mutagen/strains/<name>.json.
    3. Jalankan /reload dan cari strain di /mutagen list. Jika file dilewati, periksa log server.

    Paket data server disinkronkan ke pemain. Semua orang masih membutuhkan build Mutagen yang sama.

    {"entity":"minecraft:witch","color":"#6A2C8C","difficulty":2}

    Contoh dan pemecahan masalah

    Untuk mengganti strain bawaan, gunakan jalur file aslinya di bawah data/mutagen/mutagen/strains/. Untuk nama dan deskripsi khusus, Anda dapat menggunakan terjemahan dari paket sumber daya.

    Lihat spesifikasi paket data lengkap untuk pemetaan model, efek penglihatan, dan contoh kerja.
