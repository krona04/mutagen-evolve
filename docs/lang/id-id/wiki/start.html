    Memulai · 0.2

    Instalasi dan mulai cepat

    Pilih build dan jalankan eksperimen pertama Anda di Minecraft.

    Di halaman ini
    • Instal Mutagen
    • Transformasi pertama Anda
    • Pemecahan masalah

    Instal Mutagen

    1. Gunakan Minecraft Java Edition 1.21.1, Java 21, dan profil Fabric atau NeoForge.
    2. Pilih build yang cocok di halaman versi.
    3. Tambahkan AArchitecture API dan GeckoLib. Fabric juga memerlukan Fabric API.
    4. Letakkan file di folder mods profil. Untuk multipemain, server dan pemain memerlukan build Mutagen yang sama.

    Transformasi pertama Anda

    1. Buat Bio Workbench dan buat peralatan lab di sana.
    2. Kumpulkan sampel dari gerombolan dan gunakan Sequencer untuk mempelajari strainnya.
    3. Purifikasi sampel di Centrifuge, lalu gunakan Synthesizer untuk membuat serum.
    4. Gunakan serum di Minecraft dan lihat bilah kemajuan di panel regangan. Lihat Transformasi untuk tahapan dan pembalikannya.

    Pemecahan masalah

    Periksa apakah mod, dependensi, dan pemuat menargetkan Minecraft 1.21.1 dan hanya ada satu build Mutagen di mods. Jika game mogok, lihat di logs/latest.log. Sertakan versi loader dan mod Anda dalam laporan bug.
