    Per iniziare · 0.2

    Installazione e avvio rapido

    Scegli una build ed esegui il tuo primo esperimento in Minecraft.

    In questa pagina
    • Installa Mutageno
    • La tua prima trasformazione
    • Risoluzione dei problemi

    Installa Mutageno

    1. Utilizza Minecraft Java Edition 1.21.1, Java 21 e un profilo Fabric o NeoForge.
    2. Scegli la build corrispondente su pagina delle versioni.
    3. Aggiunta API Architecture e GeckoLib. Il tessuto richiede anche Fabric API.
    4. Inserisci i file nella cartella mods del profilo. Per il multiplayer, il server e i giocatori necessitano della stessa build Mutagen.

    La tua prima trasformazione

    1. Crea un banco da lavoro biologico e costruisci lì l'attrezzatura da laboratorio.
    2. Raccogli un campione da un mob e usa il sequenziatore per studiarne il ceppo.
    3. Purifica un campione nella centrifuga, quindi usa il sintetizzatore per produrre il siero.
    4. Usa il siero in Minecraft e osserva la barra di avanzamento nel pannello della tensione. Vedi Transformation per le fasi e l'inversione.

    Risoluzione dei problemi

    Controlla che la mod, le dipendenze e il caricatore abbiano come target Minecraft 1.21.1 e che ci sia solo una build Mutagen in mods. Se il gioco si blocca, cerca in logs/latest.log. Includi le versioni del tuo caricatore e della mod in una segnalazione di bug.
