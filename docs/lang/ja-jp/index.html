ゲームプレイ

サンプルから血清まで

サンプルを収集する

Minecraft で暴徒に近づき、注射器を使ってサンプルを採取します。

菌株を研究する

シーケンサーを使用して、より強力な血清のロックを解除します。 G を押して遺伝子ツリーを開きます。

サンプルを精製します

遠心分離機で処理して、精製されたゲノムを取得します。

血清を作る

シンセサイザーでゲノム、変異原塩基、触媒を組み合わせます。

イラスト付きレシピを見る

変身

5段階の突然変異

  1. 私感染症1–20%

    最初のパッシブ特性が表示されます。

  2. II顕現21–40%

    暴徒の斑点が皮膚に広がりました。

  3. Ⅲ突然変異41–70%

    あなたの体の形が変わり始めます。

  4. IV支配71–99%

    飛翔株が飛翔力を獲得します。ハンドレスフォームはオフハンドを失います。

  5. V完全な形式100%

    あなたは暴徒の姿をとります。変化は減衰を停止します。

投与ごとに進行が鈍化する可能性があります。完全なフォームに達したら、逆転美容液を使用して元に戻します。

インストール

  1. Minecraft 1.21.1 には Java 21 と Fabric または NeoForge プロファイルを使用してください。
  2. Architectury API と GeckoLib をインストールします。 Fabric には Fabric API も必要です。
  3. 一致するファイルをプロファイルの mods フォルダーに置きます。

Pehkui はボディ スケーリングのオプションです。
