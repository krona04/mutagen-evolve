    コントロールとコマンド

    ひずみをテストするためのプレーヤーのショートカットとオペレーター コマンド。

    このページについて
    • プレーヤーのコントロール
    • オペレーターコマンド

    プレーヤーのコントロール

    キーアクション
    G遺伝子ツリーを開く
    Nクリーチャーの視覚を切り替えます
    Rステージ II のアビリティを使用する
    Vステージ III アビリティを使用する
    B頂点アビリティを使用する

    オペレーターコマンド

    コマンド グループには権限レベル 2 が必要です。株は、mutagen:zombie または短縮名 zombie などの ID を受け入れます。括弧はオプションの引数を囲みます。

    コマンドアクション
    /mutagen status [target]緊張、進行状況、その他の状態を表示します。
    /mutagen list利用可能な株をリストします。
    /mutagen dose <strain> [quality]通常の研究上限を回避しながら投与量を追加します。品質の範囲は 1 ～ 100 です。
    /mutagen set <strain> <progress>変換の進行状況を 0 ～ 100 で設定します。
    /mutagen lock <true|false>進行状況ロックを有効または無効にします。
    /mutagen clear活性株を除去します。
    /mutagen research研究の進捗状況を表示します。
    /mutagen research <strain> <percent>株の研究を設定します。
    /mutagen abilitiesアクティブなアビリティとクールダウンを表示します。
    /mutagen use <index>インデックスによって能力を発動してみます。
