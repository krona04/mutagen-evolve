    はじめに · 0.2.1

    インストールとクイックスタート

    ビルドを選択し、Minecraft で最初の実験を実行します。

    このページについて
    • Mutagenのインストール
    • あなたの最初の変身
    • トラブルシューティング

    Mutagenのインストール

    1. Minecraft Java Edition 1.21.1、Java 21、FabricまたはNeoForgeのプロファイルを使用します。
    2. バージョン一覧から対応するファイルをダウンロードします。
    3. Architectury APIとGeckoLibを導入します。FabricではFabric APIも必要です。
    4. プロファイルのmodsフォルダーにファイルを入れます。マルチプレイでは、サーバーと全プレイヤーで同じMutagenのビルドを使ってください。

    あなたの最初の変身

    1. バイオ作業台を作り、そこで実験器具を作ります。
    2. 暴徒からサンプルを収集し、シーケンサーを使用してその系統を研究します。
    3. サンプルを遠心分離機で精製し、合成装置を使用して血清を作成します。
    4. Minecraft で血清を使用し、ひずみパネルの進行状況バーを見てください。ステージと反転については、Transformationを参照してください。

    トラブルシューティング

    MOD、依存関係、ローダーが Minecraft 1.21.1 をターゲットにしており、mods に Mutagen ビルドが 1 つだけ存在することを確認してください。ゲームがクラッシュした場合は、logs/latest.log を確認してください。バグレポートにはローダーと MOD のバージョンを含めてください。
