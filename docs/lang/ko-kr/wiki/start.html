    시작하기 · 0.2

    설치 및 빠른 시작

    빌드를 선택하고 Minecraft에서 첫 번째 실험을 실행하세요.

    이 페이지에서
    • Mutagen 설치
    • 당신의 첫 변신
    • 문제 해결

    Mutagen 설치

    1. Minecraft Java Edition 1.21.1, Java 21 및 Fabric 또는 NeoForge 프로필을 사용하세요.
    2. 버전 페이지에서 일치하는 빌드를 선택하세요.
    3. Architectury API 및 GeckoLib를 추가합니다. Fabric에는 Fabric API도 필요합니다.
    4. 프로필의 mods 폴더에 파일을 넣으세요. 멀티플레이어의 경우 서버와 플레이어는 동일한 Mutagen 빌드가 필요합니다.

    당신의 첫 변신

    1. 바이오 작업대를 만들고 그곳에서 실험실 장비를 만드세요.
    2. 몹에게서 샘플을 수집하고 시퀀서를 사용하여 몹의 변종을 연구하세요.
    3. 샘플을 원심분리기로 정제한 후 합성기를 이용해 혈청을 만듭니다.
    4. Minecraft에서 세럼을 사용하고 스트레인 패널의 진행률 표시줄을 확인하세요. 단계 및 반전은 Transformation를 참조하세요.

    문제 해결

    모드, 종속성 및 로더가 Minecraft 1.21.1을 대상으로 하고 mods에 Mutagen 빌드가 하나만 있는지 확인하세요. 게임이 충돌하면 logs/latest.log를 살펴보세요. 버그 보고서에 로더와 모드 버전을 포함하세요.
