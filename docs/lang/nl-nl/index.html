Gameplay

Van monster tot serum

Verzamel een monster

Benader een menigte in Minecraft en gebruik een injectiespuit om een monster te verzamelen.

Onderzoek de soort

Gebruik de Sequencer om sterkere serums te ontgrendelen. Druk op G om de genenboom te openen.

Zuiver het monster

Verwerk het in de centrifuge om een gezuiverd genoom te verkrijgen.

Maak een serum

Combineer een genoom, mutagene base en katalysator in de Synthesizer.

Transformatie

Vijf stadia van mutatie

  1. IkInfectie1–20%

    De eerste passieve eigenschap verschijnt.

  2. IIManifestatie21–40%

    Flarden van de menigte verspreiden zich over je huid.

  3. IIIMutatie41–70%

    Je lichaam begint van vorm te veranderen.

  4. IVOverheersing71–99%

    Vliegende soorten krijgen vlucht. Greeploze vormen verliezen de handigheid.

  5. VVolledig formulier100%

    Je neemt de vorm van de menigte aan. De verandering stopt met rotten.

Uw voortgang kan tussen de doses afnemen. Zodra je de volledige vorm hebt bereikt, gebruik je een omkeerserum om terug te keren.

Installatie

  1. Gebruik Java 21 en een Fabric- of NeoForge-profiel voor Minecraft 1.21.1.
  2. Installeer Architectury API en GeckoLib. Stof heeft ook Fabric API nodig.
  3. Plaats de overeenkomende bestanden in de map mods van het profiel.

Pehkui is optioneel voor bodyscaling.
