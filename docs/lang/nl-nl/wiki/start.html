    Aan de slag · 0.2.1

    Installatie en snelle start

    Kies een build en voer je eerste experiment uit in Minecraft.

    Op deze pagina
    • Mutageen installeren
    • Je eerste transformatie
    • Probleemoplossing

    Mutageen installeren

    1. Gebruik Minecraft Java Edition 1.21.1, Java 21 en een Fabric- of NeoForge-profiel.
    2. Kies de bijpassende build op de versions-pagina.
    3. Voeg Architectury API en GeckoLib toe. Fabric vereist ook Fabric API.
    4. Plaats de bestanden in de map mods van het profiel. Voor multiplayer hebben de server en spelers dezelfde Mutagen-build nodig.

    Je eerste transformatie

    1. Maak een biowerkbank en maak daar de laboratoriumapparatuur.
    2. Verzamel een monster van een menigte en gebruik de Sequencer om de soort te bestuderen.
    3. Zuiver een monster in de centrifuge en gebruik vervolgens de synthesizer om serum te maken.
    4. Gebruik het serum in Minecraft en bekijk de voortgangsbalk in het stampaneel. Zie Transformatie voor de fasen en omkering.

    Probleemoplossing

    Controleer of de mod, afhankelijkheden en lader op Minecraft 1.21.1 zijn gericht en of er slechts één Mutagen-build is in mods. Als het spel crasht, kijk dan in logs/latest.log. Neem uw loader- en mod-versies op in een bugrapport.
