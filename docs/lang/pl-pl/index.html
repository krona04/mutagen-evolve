Transformacja

Pięć etapów mutacji

  1. IZakażenie1–20%

    Pojawia się pierwsza cecha pasywna.

  2. IIUjawnienie21–40%

    Plamy tłumu rozpościerają się na twojej skórze.

  3. IIIMutacja41–70%

    Twoje ciało zaczyna zmieniać kształt.

  4. IVDominacja71–99%

    Latające szczepy zyskują lot. Formy bez uchwytów tracą drugą rękę.

  5. VPełna postać100%

    Przyjmujesz postać tłumu. Zmiana przestaje zanikać.

Między dawkami przemiana może się cofać. W pełnej formie użyj serum odwracającego, aby wrócić do poprzedniej postaci.

Instalacja Mutagen

  1. Użyj Minecraft Java Edition 1.21.1, Javy 21 i profilu z Fabric lub NeoForge.
  2. Zainstaluj Architectury API i GeckoLib. Fabric wymaga też Fabric API.
  3. Umieść pliki w folderze mods swojego profilu. W grze wieloosobowej serwer i gracze muszą używać tej samej wersji Mutagen.

Pehkui jest opcjonalny i odpowiada za zmianę rozmiaru ciała.
