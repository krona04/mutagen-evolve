Jogabilidade

Da amostra ao soro

Colete uma amostra

Aproxime-se de uma multidão no Minecraft e use uma seringa para coletar uma amostra.

Pesquise a cepa

Use o Sequenciador para desbloquear soros mais fortes. Pressione G para abrir a árvore genética.

Purifique a amostra

Processe na Centrífuga para obter um genoma purificado.

Faça um soro

Combine um genoma, base mutagênica e catalisador no Sintetizador.

Veja receitas ilustradas

Transformação

Cinco estágios de mutação

  1. EuInfecção1–20%

    A primeira característica passiva aparece.

  2. IIManifestação21–40%

    Manchas da multidão espalhadas pela sua pele.

  3. IIIMutação41–70%

    Seu corpo começa a mudar de forma.

  4. IVDominação71–99%

    Cepas voadoras ganham vôo. Formulários sem alça perdem a mão inábil.

  5. VFormulário completo100%

    Você assume a forma do mob. A mudança para de decair.

Seu progresso pode diminuir entre as doses. Depois de atingir a forma completa, use um soro de reversão para voltar atrás.

Instalação

  1. Use Java 21 e um perfil Fabric ou NeoForge para Minecraft 1.21.1.
  2. Instale Architectury API e GeckoLib. O Fabric também precisa do Fabric API.
  3. Coloque os arquivos correspondentes na pasta mods do perfil.

Pehkui é opcional para dimensionamento corporal.
