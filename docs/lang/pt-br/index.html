Jogabilidade

Da amostra ao soro

Colete uma amostra

Aproxime-se de uma multidão no Minecraft e use uma seringa para coletar uma amostra.

Pesquise a cepa

Use o Sequenciador para desbloquear soros mais fortes. Pressione G para abrir a árvore genética.

Purifique a amostra

Processe na Centrífuga para obter um genoma purificado.

Faça um soro

Combine um genoma, base mutagênica e catalisador no Sintetizador.

Ver receitas de fabricação ilustradas

Transformação

Cinco estágios de mutação

  1. IInfecção1–20%

    A primeira característica passiva aparece.

  2. IIManifestação21–40%

    Manchas da multidão espalhadas pela sua pele.

  3. IIIMutação41–70%

    Seu corpo começa a mudar de forma.

  4. IVDomínio71–99%

    Cepas voadoras ganham vôo. Formulários sem alça perdem a mão inábil.

  5. VForma completa100%

    Você assume a forma do mob. A mudança para de decair.

Entre as doses, a transformação pode regredir. Na forma completa, use o soro de reversão para voltar ao normal.

Instalação do Mutagen

  1. Use Minecraft Java Edition 1.21.1, Java 21 e um perfil com Fabric ou NeoForge.
  2. Instale Architectury API e GeckoLib. Para Fabric, instale também Fabric API.
  3. Coloque os arquivos na pasta mods do perfil. No multijogador, servidor e jogadores precisam usar a mesma versão do Mutagen.

Pehkui é opcional e controla as mudanças no tamanho do corpo.
