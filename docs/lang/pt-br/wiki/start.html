    Primeiros passos · 0.2.1

    Instalação e início rápido

    Escolha uma versão e execute seu primeiro experimento no Minecraft.

    Nesta página
    • Instalação do Mutagen
    • Sua primeira transformação
    • Solução de problemas

    Instalação do Mutagen

    1. Use Minecraft Java Edition 1.21.1, Java 21 e um perfil com Fabric ou NeoForge.
    2. Baixe o arquivo para seu carregador na página de versões.
    3. Instale Architectury API e GeckoLib. Para Fabric, instale também Fabric API.
    4. Coloque os arquivos na pasta mods do perfil. No multijogador, servidor e jogadores precisam usar a mesma versão do Mutagen.

    Sua primeira transformação

    1. Crie uma bancada biológica e faça o equipamento do laboratório lá.
    2. Colete uma amostra de um mob e use o Sequenciador para estudar sua cepa.
    3. Purifique uma amostra na centrífuga e depois use o sintetizador para fazer soro.
    4. Use o soro no Minecraft e observe a barra de progresso no painel de tensão. Consulte Transformation para os estágios e reversão.

    Solução de problemas

    Verifique se o mod, as dependências e o carregador têm como alvo o Minecraft 1.21.1 e se há apenas uma compilação Mutagen em mods. Se o jogo travar, procure em logs/latest.log. Inclua suas versões de carregador e mod em um relatório de bug.
