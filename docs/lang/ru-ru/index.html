Трансформация

Пять стадий мутации

  1. ЯИнфекция1–20%

    Появляется первая пассивная черта.

  2. IIПроявление21–40%

    Пятна моба распространяются по вашей коже.

  3. IIIМутация41–70%

    Ваше тело начинает менять форму.

  4. IVДоминирование71–99%

    Летающие штаммы обретают способность летать. Безручочные формы теряют броскость.

  5. ВПолная форма100%

    Вы принимаете форму моба. Изменение перестает разрушаться.

Ваш прогресс может замедлиться между дозами. Как только вы достигнете полной формы, используйте обратимую сыворотку, чтобы повернуть назад.

Установка

  1. Используйте Java 21 и профиль Fabric или NeoForge для Minecraft 1.21.1.
  2. Установите Architectury API и GeckoLib. Для ткани также требуется Fabric API.
  3. Поместите соответствующие файлы в папку mods профиля.

Pehkui не является обязательным для масштабирования тела.
