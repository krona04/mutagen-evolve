    Настройки сервера

    Параметры по умолчанию, совместимость и настройки общего мира.

    На этой странице
    • Файл настроек
    • Значения по умолчанию
    • Совместимость

    Файл настроек

    Настройки хранятся в config/mutagen.json. Чтобы у каждого игрока было своё исследование, задайте knowledgeScope значение player. Параметр humanityPenalties управляет ограничениями форм, например запретом пользоваться инструментами, если у существа нет рук.

    Значения по умолчанию

    КлавишаПо умолчаниюНазначение
    transformationSpeed1.0Скорость усвоения дозы и спада превращения.
    doseStrength20.0Прогресс, который даёт доза чистотой 100%.
    humanityPenaltiestrueВключает ограничения форм, включая потерю рук и возможности носить броню.
    sunlightBurntrueВключает горение нежити на солнце.
    hudtrueПоказывает панель штамма.
    hudCornertop_leftЗадаёт угол экрана для панели штамма. top_left, top_right, bottom_right, bottom_left.
    fullFormRendertrueОтрисовывает игрока моделью моба в полной форме.
    maxGenes1Максимум штаммов на одного игрока.
    knowledgeScopeworldОпределяет, общее ли исследование для мира или отдельное для каждого игрока. world, player.
    researchSpeed1.0Сколько даёт один запуск секвенатора.
    doubleSerumPurity85.0Минимальная чистота для двух ампул. Значение 101 отключает бонус. 101.
    hybridRendertrueПоказывает части тела моба на стадиях II–IV.
    bodyMorphtrueМеняет пропорции и позу игрока.
    bodyMotiontrueВключает конвульсии между стадиями и подёргивания после них.
    pehkuiIntegrationtrueИспользует Pehkui для масштабирования тела, если мод установлен.
    mobVisionfalseЗрение существа. Переключается клавишей N.

    Совместимость

    МодПримечания
    ПекуиПри наличии управляет размерами тела. Отключается через pehkuiIntegration. pehkuiIntegration.
    Натрий/ЭмбеддийРаботают с Mutagen.
    Ирис / ОкулусРаботают с Mutagen. Слои мутации пропускаются при отрисовке теней.
    Моды скинов и плащейИспользуется скин другого мода. В полной форме плащ скрывается.
    ФигураАватар может закрывать превращение. При конфликте отключите hybridRender или fullFormRender. hybridRender, fullFormRender.
