    Конфигурация сервера

    Значения по умолчанию, совместимость и настройки для общего мира.

    На этой странице
    • Файл конфигурации.
    • Значения по умолчанию
    • Совместимость

    Файл конфигурации.

    Найдите настройки в config/mutagen.json. Установите knowledgeScope на player для отдельного исследования для каждого игрока. humanityPenalties контролирует такие ограничения, как отказ от использования инструментов в бесручных формах.

    Значения по умолчанию

    КлючПо умолчаниюЧто он делает
    transformationSpeed1.0Насколько быстро всасываются и выводятся дозы
    doseStrength20.0Сколько добавляет одна доза 100% чистоты?
    humanityPenaltiestrueПотеря рук, брони и т. д.
    sunlightBurntrueШтаммы нежити, горящие при дневном свете.
    hudtrueПоказывает панель деформации.
    hudCornertop_leftПоложение панели: top_left, top_right, bottom_right, bottom_left.
    fullFormRendertrueНарисуйте вас как настоящего моба на этапе V.
    maxGenes1Сколько напряжений может выдержать одно тело. Химеры приходят позже
    knowledgeScopeworldworld: все делятся исследованиями. player: у каждого игрока свой
    researchSpeed1.0Чему вас учит каждое прохождение секвенсора?
    doubleSerumPurity85.0Чистота генома за две ампулы за один синтез; 101 выключает его.
    hybridRendertrueЧасти существа на вашем теле на стадиях II–IV.
    bodyMorphtrueИзменяются ваши пропорции и осанка.
    bodyMotiontrueСудороги между стадиями и подергивания в дальнейшем.
    pehkuiIntegrationtrueИспользуйте Pehkui для определения размера тела, если он установлен.
    mobVisionfalseВидение существа. Также переключается с помощью N

    Совместимость

    МодПримечания
    ПекуиУчитывает размер корпуса, если установлен. Выключите с помощью pehkuiIntegration
    Натрий/ЭмбеддийРаботает нормально
    Ирис / ОкулусРаботает; наложения мутаций пропускают проход тени
    Моды скинов и плащейВаша кожа — это всё, что вам дают. Накидка исчезает в полном виде
    ФигураВаш аватар может представлять собой гибридную или полную форму. Выключите hybridRender/fullFormRender, если они дерутся.
