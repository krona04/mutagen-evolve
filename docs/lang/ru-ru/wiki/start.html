    Начало игры · 0.2.1

    Установка и быстрый старт

    Выберите сборку и начните первое превращение в Minecraft.

    На этой странице
    • Установка Mutagen
    • Первое превращение
    • Если что-то не работает

    Установка Mutagen

    1. Запустите Minecraft Java Edition 1.21.1 на Java 21 с загрузчиком Fabric или NeoForge.
    2. Выберите подходящий файл на странице версий.
    3. Установите Architectury API и GeckoLib. Для Fabric также нужен Fabric API.
    4. Поместите файлы в папку mods вашего профиля. Для сетевой игры на сервере и у игроков должна стоять одна и та же сборка Mutagen.

    Первое превращение

    1. Скрафтите верстак биолога и соберите на нём оборудование для лаборатории.
    2. Возьмите у моба образец шприцем и изучите штамм в секвенаторе.
    3. Очистите образец в центрифуге, затем приготовьте сыворотку в синтезаторе.
    4. Введите сыворотку в игре и следите за шкалой штамма. Подробнее — в разделе «Превращение».

    Если что-то не работает

    Проверьте, что мод и зависимости подходят для Minecraft 1.21.1 и вашего загрузчика. В папке mods должна быть только одна сборка Mutagen. Если игра вылетает, откройте logs/latest.log. В отчёте об ошибке укажите версии игры, загрузчика и мода.
