Transformation

Fem stadier av mutation

  1. IInfektion1–20%

    Den första passiva egenskapen visas.

  2. IIManifestation21–40%

    Fläckar av mobben sprids över din hud.

  3. IIIMutation41–70%

    Din kropp börjar ändra form.

  4. IVDominans71–99%

    Flygande stammar tar fart. Handlösa former förlorar off-handen.

  5. VFullständigt formulär100%

    Du tar mobbens form. Förändringen slutar förfalla.

Dina framsteg kan avta mellan doserna. När du når full form, använd ett reverseringsserum för att vända tillbaka.

Installation

  1. Använd Java 21 och en tyg- eller NeoForge-profil för Minecraft 1.21.1.
  2. Installera Architectury API och GeckoLib. Tyg behöver också Fabric API.
  3. Lägg de matchande filerna i profilens mods-mapp.

Pehkui är valfritt för kroppsskalning.
