Samla ett prov

Gå fram till en mobb i Minecraft och använd en spruta för att samla ett prov.

Undersök stammen

Använd Sequencer för att låsa upp starkare serum. Tryck på G för att öppna genträdet.

Transformation

Fem stadier av mutation

  1. IInfektion1–20%

    Den första passiva egenskapen visas.

  2. IIManifestation21–40%

    Fläckar av mobben sprids över din hud.

  3. IIIMutation41–70%

    Din kropp börjar ändra form.

  4. IVDominans71–99%

    Flygande stammar tar fart. Handlösa former förlorar off-handen.

  5. VFull form100%

    Du tar mobbens form. Förändringen slutar förfalla.

Förvandlingen kan avta mellan doserna. Använd återställningsserum i full form för att återgå.

Installera Mutagen

  1. Använd Minecraft Java Edition 1.21.1, Java 21 och en profil med Fabric eller NeoForge.
  2. Installera Architectury API och GeckoLib. Fabric behöver även Fabric API.
  3. Lägg filerna i profilens mods-mapp. I flerspelarläge måste server och spelare använda samma version av Mutagen.

Pehkui är valfritt och hanterar förändringar i kroppsstorlek.
