    Operatörskommandon

    Kommandogruppen kräver behörighetsnivå 2. Stammar accepterar ett ID som mutagen:zombie eller kortnamnet zombie. Hakparenteser omger valfria argument.

    KommandoÅtgärd
    /mutagen status [target]Visa belastning, framsteg och annat tillstånd.
    /mutagen listLista tillgängliga stammar.
    /mutagen dose <strain> [quality]Lägg till en dos samtidigt som du kringgår det normala forskningslocket. Kvaliteten varierar från 1 till 100.
    /mutagen set <strain> <progress>Ställ in transformationsförlopp från 0 till 100.
    /mutagen lock <true|false>Aktivera eller inaktivera förloppslåset.
    /mutagen clearRensa aktiva stammar.
    /mutagen researchVisa forskningsframsteg.
    /mutagen research <strain> <percent>Ställ forskning för en stam.
    /mutagen abilitiesVisa de aktiva förmågorna och nedkylningarna.
    /mutagen use <index>Försök att aktivera en förmåga efter index.
