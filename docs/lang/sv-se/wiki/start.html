    Komma igång · 0.2.1

    Installation och snabbstart

    Välj ett bygge och kör ditt första experiment i Minecraft.

    På den här sidan
    • Installera Mutagen
    • Din första förvandling
    • Felsökning

    Installera Mutagen

    1. Använd Minecraft Java Edition 1.21.1, Java 21 och en profil med Fabric eller NeoForge.
    2. Hämta rätt fil på versionssidan.
    3. Installera Architectury API och GeckoLib. Fabric behöver även Fabric API.
    4. Lägg filerna i profilens mods-mapp. I flerspelarläge måste server och spelare använda samma version av Mutagen.

    Din första förvandling

    1. Skapa en Bio Workbench och gör labbutrustningen där.
    2. Samla ett prov från en mobb och använd Sequencer för att studera dess stam.
    3. Rena ett prov i centrifugen och använd sedan Synthesizer för att göra serum.
    4. Använd serumet i Minecraft och titta på förloppsindikatorn i stampanelen. Se Transformation för steg och reversering.

    Felsökning

    Kontrollera att moden, beroenden och laddaren är inriktade på Minecraft 1.21.1 och att det bara finns en Mutagen-build i mods. Om spelet kraschar, titta i logs/latest.log. Inkludera din loader- och modversioner i en felrapport.
