Dönüşüm

Mutasyonun beş aşaması

  1. benEnfeksiyon1–20%

    İlk pasif özellik ortaya çıkar.

  2. IITezahür21–40%

    Mafyanın yamaları cildinize yayıldı.

  3. IIIMutasyon41–70%

    Vücudunuz şekil değiştirmeye başlar.

  4. IVHakimiyet71–99%

    Uçan suşlar uçuş kazanır. Kulpsuz formlar hazırlıksızlığını kaybeder.

  5. VTam form100%

    Mafyanın formunu alıyorsunuz. Değişim bozulmayı durdurur.

Dozlar arasında ilerlemeniz bozulabilir. Tam forma ulaştığınızda, geri dönmek için tersine çeviren bir serum kullanın.

Kurulum

  1. Minecraft 1.21.1 için Java 21 ve Fabric veya NeoForge profilini kullanın.
  2. Architetury API ve GeckoLib'yi yükleyin. Kumaşın ayrıca Fabric API'ye ihtiyacı vardır.
  3. Eşleşen dosyaları profilin mods klasörüne koyun.
