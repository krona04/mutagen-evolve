    Конфігурація сервера

    Стандартні параметри, сумісність і налаштування для спільного світу.

    На цій сторінці
    • Файл конфігурації
    • Значення за замовчуванням

    Файл конфігурації

    Знайдіть налаштування в config/mutagen.json. Встановіть knowledgeScope на player для окремого дослідження для кожного гравця. humanityPenalties контролює такі обмеження, як втрата використання інструментів у безручних формах.

    Значення за замовчуванням

    КлючЗа замовчуваннямЩо він робить
    transformationSpeed1.0Як швидко дози поглинаються та зникають
    doseStrength20.0Скільки додає одна доза 100% чистоти
    humanityPenaltiestrueВтрата рук, обладунків і так далі
    sunlightBurntrueШтами нежиті, що горять у денному світлі
    hudtrueПоказує панель деформації
    hudCornertop_leftРозташування панелі: top_left, top_right, bottom_right, bottom_left
    fullFormRendertrueНамалюйте себе справжнім мобом на етапі V
    maxGenes1Скільки напруг може витримати одне тіло. Химери приходять пізніше
    knowledgeScopeworldworld: усі діляться дослідженнями. player: у кожного гравця вони свої
    researchSpeed1.0Чому вас навчає кожен запуск секвенсора
    doubleSerumPurity85.0Чистота геному для двох ампул на синтез; 101 вимикає його
    hybridRendertrueЧастини істоти на вашому тілі на стадіях II–IV
    bodyMorphtrueВаші пропорції та постава змінюються
    bodyMotiontrueСудоми між стадіями та посмикування пізніше
    pehkuiIntegrationtrueВикористовуйте Pehkui для розміру корпусу, якщо він встановлений
    mobVisionfalseБачення істоти. Також перемикається з N

    Сумісність

    МодПримітки
    ПехкуйВідповідає розміру корпусу, якщо встановлено. Вимкніть за допомогою pehkuiIntegration
    Натрій / EmbeddiumПрацює добре
    Ірис / ОкулусРоботи; накладення мутацій пропускають тіньовий прохід
    Моди шкіри та накидкиТвоя шкіра – це те, що тобі дають. Накидка зникає в повному вигляді
    ФігураВаш аватар може покривати гібридну або повну форму. Вимкніть hybridRender / fullFormRender, якщо вони сваряться
