    Встановлення та швидкий старт

    Виберіть збірку та запустіть свій перший експеримент у Minecraft.

    На цій сторінці
    • Встановіть Mutagen
    • Ваше перше перетворення
    • Усунення несправностей

    Встановіть Mutagen

    1. Використовуйте Minecraft Java Edition 1.21.1, Java 21 і профіль Fabric або NeoForge.
    2. Виберіть відповідну збірку на сторінка версій.
    3. Додайте Architectury API і GeckoLib. Тканина також потребує Fabric API.
    4. Помістіть файли в папку mods профілю. Для багатокористувацької гри сервер і гравці потребують однакової збірки Mutagen.

    Ваше перше перетворення

    1. Зробіть біоверстак і виготовте там лабораторне обладнання.
    2. Зберіть зразок у мобу та використовуйте Секвенсор, щоб вивчити його штам.
    3. Очистіть зразок у центрифузі, а потім за допомогою синтезатора приготуйте сироватку.
    4. Використовуйте сироватку в Minecraft і спостерігайте за індикатором прогресу на панелі навантаження. Дивіться Transformation для етапів і скасування.

    Усунення несправностей

    Переконайтеся, що мод, залежності та завантажувач націлені на Minecraft 1.21.1 і що в mods є лише одна збірка Mutagen. Якщо гра вилітає, подивіться в logs/latest.log. Включіть ваші версії завантажувача та мода у звіт про помилку.
