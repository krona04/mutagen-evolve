Chuyển đổi

Năm giai đoạn đột biến

  1. INhiễm1–20%

    Đặc điểm thụ động đầu tiên xuất hiện.

  2. IIBiểu hiện21–40%

    Các đám đông lan rộng trên da bạn.

  3. IIIĐột biến41–70%

    Cơ thể bạn bắt đầu thay đổi hình dạng.

  4. IVChi phối71–99%

    Các chủng bay đạt được chuyến bay. Các hình thức không có tay cầm sẽ mất đi sự thuận tiện.

  5. VHình dạng hoàn chỉnh100%

    Bạn mang hình dáng của đám đông. Sự thay đổi ngừng phân rã.

Quá trình biến đổi có thể thoái lui giữa các liều. Khi đạt hình dạng hoàn chỉnh, hãy dùng huyết thanh đảo ngược để trở lại.

Cài đặt Mutagen

  1. Dùng Minecraft Java Edition 1.21.1, Java 21 và hồ sơ Fabric hoặc NeoForge.
  2. Cài Architectury API và GeckoLib. Với Fabric, cài thêm Fabric API.
  3. Chép các tệp vào thư mục mods của hồ sơ. Khi chơi nhiều người, máy chủ và mọi người chơi phải dùng cùng bản Mutagen.
