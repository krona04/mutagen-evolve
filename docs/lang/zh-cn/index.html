转变

突变的五个阶段

  1. 我感染1–20%

    第一个被动特质出现。

  2. 二表现21–40%

    怪物的斑点遍布在你的皮肤上。

  3. 三突变41–70%

    你的身体开始改变形状。

  4. 四统治71–99%

    飞行菌株获得飞行。无手形式失去了副手。

  5. V完整表格100%

    你采用了暴民的形态。变化停止衰退。

您的进步可能会在剂量之间衰减。一旦达到完全状态，请使用逆转血清来逆转。

安装

  1. 使用适用于 Minecraft 1.21.1 的 Java 21 和 Fabric 或 NeoForge 配置文件。
