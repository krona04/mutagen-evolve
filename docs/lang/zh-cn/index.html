游戏玩法

从样本到血清

采集样本

接近 Minecraft 中的生物并使用注射器收集样本。

研究菌株

使用序列器解锁更强的血清。按 G 打开基因树。

纯化样品

在离心机中处理以获得纯化的基因组。

制作精华液

在合成器中组合基因组、诱变剂碱基和催化剂。

查看带图的合成配方

转变

突变的五个阶段

  1. I感染1–20%

    第一个被动特质出现。

  2. II显现21–40%

    怪物的斑点遍布在你的皮肤上。

  3. III变异41–70%

    你的身体开始改变形状。

  4. IV支配71–99%

    飞行菌株获得飞行。无手形式失去了副手。

  5. V完全形态100%

    你采用了暴民的形态。变化停止衰退。

两次注射之间，变身进度可能回退。达到完全形态后，可使用逆转血清恢复原状。

各种生物的优势与弱点

展开变异株卡片以查看其特性。

僵尸

力量 在黑暗中再生

弱点 在阳光下燃烧

骷髅

力量 箭矢伤害更高

弱点 脆弱的骨头

苦力怕

强度 苦力怕不再对你嘶嘶作响

弱点 靠近猫时惊慌

蜘蛛

力量 攀爬墙壁：贴着墙即可向上爬，潜行可以抓住不放

弱点 易受火焰伤害

末影人

Strength 长腿可以跨过整个方块

弱点 水和雨像酸一样灼烧

溺尸

力量 鳃：可在水下呼吸

弱点 在陆地上笨拙

烈焰人

Strength 飞行：连按两次跳跃。飞行消耗饥饿值；雨和水会让你无法飞行

弱点 水和雨会浇灭火焰，并造成伤害

幻翼

强度 飞行：连按两次跳跃。飞行消耗饥饿值；雨和水会让你无法飞行

弱点 在阳光下燃烧

蜜蜂

力量 花粉：附近的作物和树苗长得更快

弱点 以甜食为生：蜂蜜、浆果、水果

狼

Strength 像狼一样奔跑

弱点 只吃肉

猪灵

力量 无论有没有金子，猪灵都视你为同类

弱点 贪金：不丢弃任何金色的东西

守卫者

力量 水栖之躯：带浮力的快速游泳、鳃以及清晰的水下视野

弱点 只能在水中呼吸；在陆地上会缺氧，视线变得浑浊

安装 Mutagen

  1. 使用 Minecraft Java Edition 1.21.1、Java 21，以及 Fabric 或 NeoForge 配置。
  2. 安装 Architectury API 和 GeckoLib。使用 Fabric 时还需安装 Fabric API。
  3. 将文件放进当前配置的 mods 文件夹。多人游戏时，服务器和所有玩家须使用同一个 Mutagen 构建版本。

Pehkui 是用于改变身体尺寸的可选模组。
