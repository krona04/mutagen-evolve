    管理·0.2.1

    数据包

    为您的 Minecraft 世界创建、覆盖或配置虚构的生物种类。

    在本页
    • 制作应变
    • 应变、身体和视野
    • 特质类型
    • 能力类型
    • 示例和故障排除

    制作应变

    1. 在世界的 datapacks 文件夹中使用 Minecraft 1.21.1 的 pack.mcmeta 创建数据包。
    2. 在 data/<namespace>/mutagen/strains/<name>.json 处放置应变。
    3. 运行/reload并查找/mutagen list中的菌株。如果文件被跳过，请检查服务器日志。

    服务器数据包同步到玩家。每个人仍然需要相同版本的 Mutagen。

    {"entity":"minecraft:witch","color":"#6A2C8C","difficulty":2}

    应变、身体和视野

    场必填默认这是什么
    entity是的该菌株来自暴徒。每个生物一株
    color没有#7FAE6B"#RRGGBB" 或一个数字。用于 HUD、颗粒以及 skin: color 感染
    scale没有1.0完整形式的渲染比例
    difficulty没有11–10。较难的物种需要更长的时间来测序
    synthesis没有catalyst（项目，默认：诱变剂催化剂），catalyst_count（1–64，默认1），time（默认300）
    body没有身体如何变化，见下文
    traits没有[]被动特质，见下文
    abilities没有[]主动能力，见下文。订单事宜
    vision没有生物视觉，见下文
    场默认这是什么
    model_layer<entity>#main从哪个香草模型层获取零件，例如"minecraft:zombie" 或 "minecraft:drowned#outer"
    parts与姓名匹配每个玩家骨骼成为生物的哪一部分。每个条目：part（模型中的路径，如 "head" 或 "body/tail"）、bone（玩家骨骼）、grow（true 表示人类没有的部分，如尾巴）、scale ([x, y, z])
    absorb[]应融入躯干的玩家骨骼。没有匹配部分的骨骼会自动执行此操作
    spread右臂、身体、左臂、头、腿骨骼顺序开始改变，皮肤扩散
    skincolor仅适用于第一人称手牌和较旧的方法：texture 从生物的纹理中获取感染颜色（仅限玩家形状的纹理），color 使用应变颜色
    morph[]额外姿势：bone 和 rotation（以度为单位）
    width、height、eye_height暴徒自己的完整形式的 Hitbox 和眼高
    reach0完整形式的区块额外触及范围（可以为负）
    overlays[]在混合体上绘制额外图层：texture，可选 model_layer、emissive 用于发光眼睛
    场默认这是什么
    shader后期效果链，例如"minecraft:shaders/post/creeper.json"，或者您自己的资源包
    from_stagemanifestation当异象开始时。随着进度的增加，它会变得更强，并达到 100%

    特质类型

    类型字段它的作用
    attributeattribute、amount、operation（add_value / add_multiplied_base / add_multiplied_total）任何属性：生命值、速度、伤害、护甲、步高、重力、游泳速度……负数也可以
    effect_immunityeffects不受这些影响
    damage_factordamage_type（损坏类型标签，例如"#minecraft:is_fire"），factor倍增传入伤害。 0 = 免疫，高于 1 = 弱点
    dark_regenerationamplifier, max_light黑暗中再生
    permanent_effecteffect, amplifier始终开启的效果
    dark_effecteffect、amplifier、max_light仅在黑暗中有效的效果
    water_effecteffect, amplifier仅在水中有效的效果
    arrow_powerfactor你的箭射得更厉害
    mob_neutralitykin（实体标签）和/或 entities这些怪物不再瞄准你
    wall_climb像蜘蛛一样爬墙
    web_walker蜘蛛网不会减慢你的速度
    thornsdamage伤害任何在近战中击中你的人
    on_hit_effecteffect、duration、amplifier、self_damage你的近战攻击会产生效果；可能会损害你的健康
    growth_auraradius, tries附近的农作物和树苗生长得更快
    flightspeed、exhaustion、min_food、rain创意风格的飞行。饥饿的代价；停在下面 min_food，并且在雨中/水中，如果 rain 是 false
    aquatic_body快速、有浮力的游泳、鳃和清晰的水下视野
    类型字段它的作用
    sun_burn白天不戴头盔被灼伤
    water_damageamount, rain水（和雨）会痛
    dry_outgrace（秒）、amount离开水太久后会变弱，然后受伤
    water_dependence仅在水中呼吸；在陆地上跳跃和视力不佳
    cat_fearradius猫和豹猫附近的恐慌
    fearentities, radius这些怪物附近的恐慌
    homesickdimension, effects在其主维度之外获得这些效果
    hoarditems（物品标签）这些物品不能扔掉
    dietfoods（物品标签）只吃这些食物
    no_eatingfood_level根本不吃东西；饥饿停留在food_level
    no_sleep睡不着
    armor_rejectionslots（默认：全部四个）无法在这些位置穿盔甲
    no_offhand不可副手
    no_toolsmutagen:needs_hands 不能容纳任何东西
    no_craftingstations（块标签），grid无法使用这些电台；使用 grid，甚至没有库存制作网格
    no_building无法放置方块（门、箱子和杠杆仍然有效）
    inventory_limithotbar只有这么多的快捷栏插槽；其余库存被锁定

    能力类型

    场默认这是什么
    type以下类型之一
    from_stage解锁时
    name显示在 HUD 和基因树中
    cooldown200以刻度为单位
    cost免费hunger 和/或 health。饱和度优先；健康永远不会带走最后一颗心
    apexfalseB能力
    requiresanywater、dry、airborne、ground、nether 或 dark
    类型字段它的作用
    effect_bursteffects、duration、amplifier给你效果
    leappower、lift、effects、duration、amplifier跳到你看的地方；之后的可选效果
    shockwaveradius、damage、knockback、ignite撞击并推动你周围的一切
    volleyarrows、spread、velocity、damage发射无法拾取的扇形箭
    fireballcount, spread发射小火球
    hexrange 或 radius、damage、effects、duration、amplifier、particle、sound如果设置了 radius，则魔法会击中您正在查看的目标或您周围的每个人
    vortexradius、pull、damage、duration吸引所有人并减慢他们的速度
    lungerange、power、damage将你扔向目标；点击联系
    blinkrange、effects、duration传送到你正在寻找的安全地点
    revealradius, duration让你周围的生物透过墙壁发光
    rallykin（实体标签）和/或 entities、radius、duration让附近的小怪攻击最后伤害你的人。什么也没有产生
