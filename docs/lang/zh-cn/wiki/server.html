    配置文件

    找到config/mutagen.json中的设置。将 knowledgeScope 设置为 player，以便每个玩家单独研究。 humanityPenalties控制诸如失去无手柄形式的工具使用等限制。

    默认值

    钥匙默认它的作用
    transformationSpeed1.0剂量吸收和消退的速度有多快
    doseStrength20.0一剂 100% 纯度的剂量会增加多少
    humanityPenaltiestrue失去双手、盔甲等
    sunlightBurntrue不死族在白天燃烧
    hudtrue显示应变面板
    hudCornertop_left面板位置：top_left、top_right、bottom_right、bottom_left
    fullFormRendertrue将您绘制为第五阶段的实际生物
    maxGenes1一个身体可以承受多少压力。嵌合体稍后出现
    knowledgeScopeworldworld：大家分享研究。 player：每个玩家都有自己的
    researchSpeed1.0每次测序仪运行可以教会您多少知识
    doubleSerumPurity85.0每次合成两个安瓿的基因组纯度； 101 将其关闭
    hybridRendertrue第二阶段至第四阶段该生物在你身上的部位
    bodyMorphtrue你的比例和姿势发生变化
    bodyMotiontrue阶段之间抽搐，随后抽搐
    pehkuiIntegrationtrue如果已安装，请使用 Pehkui 作为车身尺寸
    mobVisionfalse生物视觉。也用 N 切换

    模组备注
    佩奎处理车身尺寸（如果已安装）。用 pehkuiIntegration 关闭

    虹膜 / 眼珠有效；突变叠加跳过阴影通道
    皮肤和斗篷模组你的皮肤就是他们给你的任何东西。斗篷完全消失
    图古拉您的头像可能涵盖混合形式或完整形式。如果 hybridRender / fullFormRender 打架，请关闭它们
