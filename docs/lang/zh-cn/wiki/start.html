    入门·0.2

    安装与快速启动

    选择一个版本并在 Minecraft 中运行您的第一个实验。

    在本页
    • 安装诱变剂
    • 你的第一次转变
    • 故障排除

    安装诱变剂

    1. 使用 Minecraft Java 版 1.21.1、Java 21 以及 Fabric 或 NeoForge 配置文件。
    2. 在 版本页面 上选择匹配的版本。
    3. 添加 Architectury API 和 GeckoLib。 Fabric 还需要 Fabric API。
    4. 将文件放入配置文件的 mods 文件夹中。对于多人游戏，服务器和玩家需要相同的 Mutagen 构建。

    你的第一次转变

    1. 制作一个生物工作台并在那里制作实验室设备。
    2. 从暴民身上收集样本并使用测序仪研究其菌株。
    3. 在离心机中纯化样品，然后使用合成器制备血清。
    4. 在 Minecraft 中使用血清并观察应变面板中的进度条。有关阶段和反转，请参阅 Transformation。

    故障排除

    检查 mod、依赖项和加载程序是否以 Minecraft 1.21.1 为目标，并且 mods 中只有一个 Mutagen 版本。如果游戏崩溃，请查看 logs/latest.log。在错误报告中包含您的加载程序和模组版本。
