    管理·0.2.1

    資料包

    為您的 Minecraft 世界創造、覆蓋或配置虛構的生物種類。

    在本頁
    • 製作應變
    • 應變、身體與視野
    • 特質類型
    • 能力類型
    • 範例與故障排除

    製作應變

    1. 在世界的 datapacks 資料夾中使用 Minecraft 1.21.1 的 pack.mcmeta 建立資料包。
    2. 在 data/<namespace>/mutagen/strains/<name>.json 處放置應變。
    3. 運行/reload並找出/mutagen list中的菌株。如果檔案被跳過，請檢查伺服器日誌。

    伺服器封包同步到玩家。每個人仍然需要相同版本的 Mutagen。

    {"entity":"minecraft:witch","color":"#6A2C8C","difficulty":2}

    應變、身體與視野

    場必填預設這是什麼
    entity是的該菌株來自暴徒。每個生物一株
    color沒有#7FAE6B"#RRGGBB" 或一個數字。用於 HUD、顆粒以及 skin: color 感染
    scale沒有1.0完整形式的渲染比例
    difficulty沒有11–10。較難的物種需要更長的時間來定序
    synthesis沒有catalyst（項目，預設：誘變劑催化劑），catalyst_count（1–64，預設1），time（預設300）
    body沒有身體如何變化，見下文
    traits沒有[]被動特質，見下文
    abilities沒有[]主動能力，見下文。訂單事宜
    vision沒有生物視覺，見下文
    場預設這是什麼
    model_layer<entity>#main從哪個香草模型層取得零件，例如"minecraft:zombie" 或 "minecraft:drowned#outer"
    parts與姓名匹配每位玩家骨骼成為生物的哪一部分。每個條目：part（模型中的路徑，如 "head" 或 "body/tail"）、bone（玩家骨骼）、grow（true 表示人類沒有的部分，如尾巴）、scale ([x, y, z])
    absorb[]應融入軀幹的玩家骨骼。沒有匹配部分的骨骼會自動執行此操作
    spread右臂、身體、左臂、頭、腿骨骼順序開始改變，皮膚擴散
    skincolor僅適用於第一人稱手牌和較舊的方法：texture 從生物的紋理中獲取感染顏色（僅限玩家形狀的紋理），color 使用應變顏色
    morph[]額外姿勢：bone 和 rotation（以度為單位）
    width、height、eye_height暴徒自己的完整形式的 Hitbox 與眼高
    reach0完整形式的區塊額外觸及範圍（可為負數）
    overlays[]在混合體上繪製額外圖層：texture，選配 model_layer、emissive 用於發光眼睛
    場預設這是什麼
    shader後製效果鏈，例如"minecraft:shaders/post/creeper.json"，或您自己的資源包
    from_stagemanifestation當異象開始時。隨著進度的增加，它會變得更強，並達到 100%

    特質類型

    型字段它的作用
    attributeattribute、amount、operation（add_value / add_multiplied_base / add_multiplied_total）任何屬性：生命值、速度、傷害、護甲、步高、重力、游泳速度…負數也可以
    effect_immunityeffects不受這些影響
    damage_factordamage_type（損壞型別標籤，例如"#minecraft:is_fire"），factor倍增傳入傷害。 0 = 免疫，高於 1 = 弱點
    dark_regenerationamplifier, max_light黑暗中再生
    permanent_effecteffect, amplifier始終開啟的效果
    dark_effecteffect、amplifier、max_light僅在黑暗中有效的效果
    water_effecteffect, amplifier僅在水中有效的效果
    arrow_powerfactor你的箭射得更厲害
    mob_neutralitykin（實體標籤）和/或 entities這些怪物不再瞄準你
    wall_climb像蜘蛛一樣爬牆
    web_walker蜘蛛網不會減慢你的速度
    thornsdamage傷害任何在近戰中擊中你的人
    on_hit_effecteffect、duration、amplifier、self_damage你的近戰攻擊會產生效果；可能會損害你的健康
    growth_auraradius, tries附近的農作物和樹苗生長得較快
    flightspeed、exhaustion、min_food、rain創意風格的飛行。飢餓的代價；停在下面 min_food，並且在雨中/水中，如果 rain 是 false
    aquatic_body快速、有浮力的游泳、鰓和清晰的水下視野
    型字段它的作用
    sun_burn白天不戴頭盔被灼傷
    water_damageamount, rain水（和雨）會痛
    dry_outgrace（秒）、amount離開水太久後會變弱，然後受傷
    water_dependence僅在水中呼吸；在陸地上跳躍和視力不佳
    cat_fearradius貓和豹貓附近的恐慌
    fearentities, radius這些怪物附近的恐慌
    homesickdimension, effects在其主維度之外獲得這些效果
    hoarditems（物品標籤）這些物品不能丟掉
    dietfoods（物品標籤）只吃這些食物
    no_eatingfood_level根本不吃東西；飢餓停留在food_level
    no_sleep睡不著
    armor_rejectionslots（預設：全部四個）無法在這些位置穿著盔甲
    no_offhand不可副手
    no_toolsmutagen:needs_hands 不能容納任何東西
    no_craftingstations（區塊標籤），grid無法使用這些電台；使用 grid，甚至沒有庫存製作網格
    no_building無法放置方塊（門、箱子和槓桿仍然有效）
    inventory_limithotbar只有這麼多的快捷欄插槽；其餘庫存被鎖定

    能力類型

    場預設這是什麼
    type以下類型之一
    from_stage解鎖時
    name顯示在 HUD 和基因樹中
    cooldown200以刻度為單位
    cost免費hunger 和/或 health。飽和度優先；健康絕對不會帶走最後一顆心
    apexfalseB能力
    requiresanywater、dry、airborne、ground、nether 或 dark
    型字段它的作用
    effect_bursteffects、duration、amplifier給你效果
    leappower、lift、effects、duration、amplifier跳到你看的地方；之後的可選效果
    shockwaveradius、damage、knockback、ignite撞擊並推動你周圍的一切
    volleyarrows、spread、velocity、damage發射無法拾取的扇形箭
    fireballcount, spread發射小火球
    hexrange 或 radius、damage、effects、duration、amplifier、particle、sound如果設定了 radius，則魔法會擊中您正在查看的目標或您周圍的每個人
    vortexradius、pull、damage、duration吸引所有人並減慢他們的速度
    lungerange、power、damage將你丟向目標；點擊聯繫
    blinkrange、effects、duration傳送到你正在尋找的安全地點
    revealradius, duration讓你周圍的生物透過牆壁發光
    rallykin（實體標籤）和/或 entities、radius、duration讓附近的小怪攻擊最後傷害你的人。什麼也沒有產生

    範例與故障排除

    若要取代內建菌株，請使用 data/mutagen/mutagen/strains/ 下的原始檔案路徑。對於自訂名稱和描述，您可以使用資源包中的翻譯。

    請參閱 完整資料包規格 以了解模型對應、視覺效果和工作範例。
