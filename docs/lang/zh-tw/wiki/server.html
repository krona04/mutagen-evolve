    管理·0.2.1

    伺服器配置

    共享世界的預設值、相容性和設定。

    在本頁
    • 設定檔
    • 預設值
    • 相容性

    設定檔

    找到config/mutagen.json中的設定。將 knowledgeScope 設定為 player，以便每位玩家單獨研究。 humanityPenalties控制諸如失去無手柄形式的工具使用等限制。

    預設值

    鑰匙預設它的作用
    transformationSpeed1.0劑量吸收和消退的速度有多快
    doseStrength20.0一劑 100% 純度的劑量會增加多少
    humanityPenaltiestrue失去雙手、盔甲等
    sunlightBurntrue不死族在白天燃燒
    hudtrue顯示應變面板
    hudCornertop_left面板位置：top_left、top_right、bottom_right、bottom_left
    fullFormRendertrue將您繪製為第五階段的實際生物
    maxGenes1一個身體可以承受多少壓力。嵌合體稍後出現
    knowledgeScopeworldworld：大家分享研究。 player：每個玩家都有自己的
    researchSpeed1.0每次定序儀運作可以教您多少知識
    doubleSerumPurity85.0每次合成兩個安瓿的基因組純度；101 將其關閉
    hybridRendertrue第二階段至第四階段該生物在你身上的部位
    bodyMorphtrue你的比例和姿勢發生變化
    bodyMotiontrue階段之間抽搐，隨後抽搐
    pehkuiIntegrationtrue若已安裝，請使用 Pehkui 作為車身尺寸
    mobVisionfalse生物視覺。也用 N 切換

    相容性

    模組備註
    佩奎處理車身尺寸（如果已安裝）。用 pehkuiIntegration 關閉
    鈉/嵌入工作正常
    虹膜 / 眼珠有效；突變疊加跳過陰影通道
    皮膚和斗篷模組你的皮膚就是他們給你的任何東西。斗篷完全消失
    圖古拉您的頭像可能涵蓋混合形式或完整形式。如果 hybridRender / fullFormRender 打架，請關閉它們
