    入門·0.2

    安裝與快速啟動

    選擇一個版本並在 Minecraft 中運行您的第一個實驗。

    在本頁
    • 安裝誘變劑
    • 你的第一次轉變
    • 故障排除

    安裝誘變劑

    1. 使用 Minecraft Java 版 1.21.1、Java 21 以及 Fabric 或 NeoForge 設定檔。
    2. 在 版本頁面 上選擇相符的版本。
    3. 新增 Architectury API 和 GeckoLib。 Fabric 還需要 Fabric API。
    4. 將檔案放入設定檔的 mods 資料夾中。對於多人遊戲，伺服器和玩家需要相同的 Mutagen 版本。

    你的第一次轉變

    1. 製作一個生物工作台並在那裡製作實驗室設備。
    2. 從暴民身上收集樣本並使用定序儀研究其菌株。
    3. 在離心機中純化樣品，然後使用合成器製備血清。
    4. 在 Minecraft 中使用血清並觀察應變面板中的進度條。有關階段和反轉，請參閱 Transformation。

    故障排除

    檢查 mod、依賴項和載入程式是否以 Minecraft 1.21.1 為目標，且 mods 中只有一個 Mutagen 版本。如果遊戲崩潰，請查看 logs/latest.log。在錯誤報告中包含您的載入程式和模組版本。
