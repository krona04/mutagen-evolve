    Getting started · 0.2.1

    Installation and quick start

    Choose a build and run your first experiment in Minecraft.

    On this page
    • Install Mutagen
    • Your first transformation
    • Troubleshooting

    Install Mutagen

    1. Use Minecraft Java Edition 1.21.1, Java 21, and a Fabric or NeoForge profile.
    2. Choose the matching build on the versions page.
    3. Add Architectury API and GeckoLib. Fabric also requires Fabric API.
    4. Put the files in the profile’s mods folder. For multiplayer, the server and players need the same Mutagen build.

    Your first transformation

    1. Craft a Bio Workbench and make the lab equipment there.
    2. Collect a sample from a mob and use the Sequencer to study its strain.
    3. Purify a sample in the Centrifuge, then use the Synthesizer to make serum.
    4. Use the serum in Minecraft and watch the progress bar in the strain panel. See Transformation for the stages and reversal.

    Troubleshooting

    Check that the mod, dependencies and loader target Minecraft 1.21.1 and that there is only one Mutagen build in mods. If the game crashes, look in logs/latest.log. Include your loader and mod versions in a bug report.
